# 推しビジュ6選 (oshi-visual-6) — v3

MUZE TOOL BOX のツール「推しビジュ6選」。
GitHub Pages にそのまま置ける静的サイトです（ビルド不要）。

## ファイル構成

```
oshi-visual-6/
├── index.html          … ページ本体(HTML/CSS)
├── assets/
│   └── js/
│       └── app.js      … ロジック + 結果画像の描画(3デザイン)
├── images/             … メンバー候補画像(変更なし)
└── README.md
```

## v3 の変更点

### 追加
- 結果画像デザインを3種類から選べるように
  - **スクラップ** … 紙もの・マステ・ノート風(ピンク/ミント/生成り)
  - **アーカイブ** … 大きな MY VISUAL 6 の雑誌・紙面レイアウト風
  - **証明写真** … PROFILE REGISTRATION SHEET 風(罫線・バーコード・スタンプ・ID CODE入り)
- 共通ヘッダー(MUZE TOOL BOX ナビ)。紙のインデックスタブ風。
  PCは横並び、スマホは横スクロール。
  ※ リンクURLは index.html の `<nav class="global-nav">` 内コメント参照。
    未定のツールは `href="#"` の仮リンクです。
- 「表示する推し名を入力」欄
  - 入力あり → 結果画像の名前部分に入力名を表示(証明写真デザインではGROUP欄は空欄罫線に)
  - 空欄 → 選択中のMAZZELメンバー名を自動表示
- 保存フォールバック: X などのアプリ内ブラウザでは自動DLできないことが
  多いため、画像を表示して「長押しで保存」の案内を出します。

### ズレ防止の仕組み(重要)
- html2canvas は不使用。
- **プレビュー自体が保存画像と同じ 1200×1200 の Canvas** で、
  同じ描画関数 `drawDesign()` を共用しています(CSSで縮小表示するだけ)。
  → 写真位置・ラベル位置・名前位置がプレビューと保存でズレることは構造上ありません。
- 各デザインの座標は app.js の `SCRAP` / `ARCHIVE` / `IDCARD` 定数にまとまっています。

### テーマの並び順(固定)
上段: 沼落ち / 最愛 / かわいい
下段: かっこいい / **ずるい(下段中央)** / **殿堂入り(下段右)**

### 削除
- 背景テーマ選択(ベリー/ソーダ/クラシカル)
- 白手書きラベル画像前提の実装(assets/handwrite/ ごと削除)
- ポエム風テキスト(selected by〜 など)
- 未使用JS(muze-core.js / muze-image.js)、.DS_Store

### 維持
- MAZZELメンバー選択(切替でリセット)
- 候補20枚から選ぶ / 自分の画像アップロード(長辺2048pxに自動縮小)
- アップロード画像の位置調整(左右・上下・拡大)
- 保存(共有シート→DL→長押し案内) / 1200×1200px PNG
- GitHub Pages で動く静的構成

## v3.2 更新(フォント統一・品質調整)

レイアウトの大枠は3デザインとも維持したまま、フォント・文字サイズ・余白・装飾の強弱を調整。

### 使用フォント(4ファミリーに統一)
| 用途 | フォント | ウェイト |
|---|---|---|
| 日本語メイン | Zen Kaku Gothic New | 400 / 500 / 700 (600指定は700で描画) |
| 日本語手書き風 | Klee One | 400 / 600 |
| 欧文サンセリフ | Montserrat | 500 / 600 / 700 |
| 欧文セリフ(英字専用) | DM Serif Display | 400 |

Shippori Mincho / Playfair Display / Caveat / Courier は廃止。日本語に明朝・serif・cursive・system-uiは一切使用しない。

### フォント指定箇所
- CSS: `index.html` の `:root`(--font-jp / --font-jp-hand / --font-en-sans / --font-en-serif。旧 --hand / --gothic はエイリアス)
- Canvas: `assets/js/app.js` の `F` オブジェクト(F.jp / F.jpHand / F.en / F.enSerif)。全 `ctx.font` がこの定義を参照
- 推し名は `containsJapanese()` 判定で、英字のみ→DM Serif Display 400、日本語含む→Zen Kaku Gothic New 600 に自動切替(`nameFontTpl()`)
- `ensureFonts()` が描画前に日本語サンプル文字列付きで全ウェイトを読み込み(`document.fonts.load` + `fonts.ready`)

### 検証
- 3デザインとも `window.createResultCanvas()`(保存経路)と `#previewCanvas`(プレビュー)の PNG が完全一致することを確認済み

## v3.3 更新(手書きフォント「花とちょうちょ」導入・ラベル文言統一)

- `assets/fonts/hana-to-choucho.ttf` を追加(元ファイル名「花とちょうちょ.ttf」を半角英数字に変更)

- **花とちょうちょはスクラップの写真下6ラベル専用**(Canvasの `drawTicketLabel` / weight 400 / 文字色 #5a4036)。UI・共通ヘッダー・他デザイン・その他の日本語には未使用

- Canvas側 `F.jpHand` = HanaToChoucho系(使用箇所は切符ラベルのみ)、`F.jpKlee` = Klee系
- `ensureFonts()` に `document.fonts.load("400 60px 'HanaToChoucho'", ラベル文字サンプル)` を追加
- ラベル文言を全デザインで統一: 沼落ちビジュ / 今の最愛ビジュ / かわいい / かっこいい / ずるい / 殿堂入り(順序不変)。長い2ラベルは fitText による自動縮小で枠内に収まる(アーカイブのラベルにも自動縮小を追加)
- アーカイブの VISUAL KEYWORDS のハッシュタグも正式表記に統一
- 検証: HanaToChoucho の読込 (`document.fonts.check`) = true、3デザインとも プレビューPNG == 保存PNG(完全一致)、モバイル390pxで崩れなし
