# 推しビジュ6選 改善版

現在公開中のデザイン・文言・画像・操作手順を変えず、スマホで不安定になりやすい内部処理だけを改善した版です。

## 主な変更

- アップロード画像を長辺2048pxまで自動縮小
  - スマホで撮影した大容量写真を6枚読み込んだ際のメモリ負荷を軽減
  - 20MBを超える画像や画像以外のファイルには日本語でエラー表示
- Canvas保存処理を共通部品へ統一
  - 対応端末では共有シートを表示
  - 非対応端末ではBlob URLでダウンロード
  - 共有のキャンセルはエラー扱いにしない
  - 保存失敗時はスクリーンショット案内を表示
- プレビューと保存画像で同じ位置・拡大計算を使用
- 写真選択モーダルをEscキーで閉じられるよう改善
- モーダルを閉じたあと、元のボタンへフォーカスを戻すよう改善
- 使用されていなかった、バージョン未固定のhtml2canvas読み込みを削除
- `.DS_Store` を削除

## 追加されたファイル

- `assets/js/muze-core.js`
- `assets/js/muze-image.js`

どちらもFable 5が作成した `muze-tool-kit` の共通部品を、外部リポジトリに依存しない形でこのツール内へ同梱しています。

## GitHubへの反映方法

### GitHub Desktopで既存リポジトリを管理している場合

1. 念のため、現在のリポジトリフォルダを複製してバックアップします。
2. このZIPを解凍します。
3. 解凍したフォルダ内のすべてのファイルとフォルダを、既存の `oshi-visual-6` ローカルフォルダへコピーします。
4. 「同じ名前のファイルを置き換える」を選びます。
5. GitHub Desktopで変更内容を確認します。
6. Summaryに `Improve image upload and save flow` などを入力してCommitします。
7. `Push origin` を押します。
8. GitHub Pagesへ反映後、スマホで動作確認します。

## 公開前に確認すること

- 8人すべてで候補画像が表示される
- JPGとPNGの候補画像が選べる
- 6テーマすべて選択できる
- 自分の写真をアップロードできる
- 左右・上下・拡大の調整がプレビューに反映される
- 保存画像でも同じ位置に見える
- iPhoneのSafariで共有シートが開く
- Android ChromeまたはPCで画像を保存できる
- モーダルを背景タップ、×、Escで閉じられる
